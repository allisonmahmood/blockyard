# Screenshot data

These are unretouched captures of Blockyard's Qt interface, treemap and theme adapter using an illustrative controller fixture. Folder names, paths, counts, capacity and sizes are demo data. They do not show a real filesystem scan or cleanup operation.

The dark screenshots use Tokyo Night; the light screenshot uses Catppuccin Latte. Each image is 1440 × 900 pixels. Both show the same demo folders.
