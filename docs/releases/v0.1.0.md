Blockyard's first release is a native Qt disk-space explorer for Omarchy.

- Explore storage through a nested treemap, folder list, search and keyboard navigation.
- Follow the active Omarchy theme and font while the app is running, including light themes.
- Review selected paths before moving them to Trash or separately confirming permanent removal.
- See allocated bytes, file sizes, hard-link accounting and scan issues without assuming selected bytes equal freed space.

## Install on Omarchy / Arch Linux

Download `blockyard-0.1.0-1-x86_64.pkg.tar.zst` and `SHA256SUMS` from this release. In that download directory:

```sh
sha256sum --ignore-missing --check SHA256SUMS
sudo pacman -U ./blockyard-0.1.0-1-x86_64.pkg.tar.zst
blockyard
```

Use an up-to-date x86_64 Omarchy or Arch installation. The package uses system Qt libraries. It also adds Blockyard to the application launcher. Other Linux distributions can build the included source archive with Qt 6.4 or later; this Arch package is not a universal Linux binary.

The package is unsigned. Download it from this repository's release and verify its checksum. If your package policy requires signatures for local packages, build from the included source instead of weakening that policy.

The AUR recipe is included in `blockyard-0.1.0-arch-build.tar.gz`, containing `PKGBUILD` and `.SRCINFO`. AUR publication is deferred until account registration is available.

## Validation and limits

All six test suites run during the clean Arch package build, followed by installation and an application launch in that disposable runner. Separate Ubuntu CI covers Qt 6.4. Local validation also covered 22 installed Omarchy palettes and adversarial cleanup tests. Filesystem mutation tests use disposable fixtures.

Trash preserves files and usually retains their space. Blockyard supports the home Trash on the same filesystem. Mounted descendants, linked Git worktrees and recognized protected data are excluded from cleanup. Btrfs snapshots, compression and shared blocks can make totals differ from space actually freed. See the repository's engine documentation for details.
